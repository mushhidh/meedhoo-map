HULHUDHOO–MEEDHOO HOUSE MAP — BETA WEBSITE

1. Extract the ZIP and deploy index.html to HTTPS hosting (e.g., Netlify Drop, GitHub Pages).
2. Open the HTTPS website in Safari on iPhone or another full browser.
3. Search house names, roads or landmarks; tap a result to zoom; toggle the old PDF layer if desired.
4. Tap the crosshair to start live GPS and allow location permission.
5. Tap Share for a link to the selected address once the site is publicly hosted.

House addresses are estimated locations extracted from a dated 21 Nov 2018 map, not cadastral coordinates. Live GPS has its own error. Actual roads, houses, and labels may have changed. More accurate property boundaries need verified geographical parcel data.

No account or custom server needed. The website does not collect GPS data through a backend; third-party basemap providers receive normal map tile requests. Online connection is needed to load basemaps and Leaflet.

PRIVACY: The website includes all 2,522 labels from the PDF; publishing without access controls makes these searchable by people who can visit the link.
